# cursa-plan-v3
**Una pagina para ayudar a los ingresantes y alumnos de FaCENA - UNNE**

## Versiones previas

Este es la version numero 3 que hago del mismo proyecto. Los anteriores estaban desarrollado en Astro, el cual es muy bueno pero llegó un punto que necesitaba mas interactividad el cual se me complicaba.

## Sobre el proyecto

Esta página busca ayudar a los estudiantes de FaCENA - UNNE en su cursada. Dado que el sistema de cursada de FaCENA no ofrece toda la información que los estudiantes necesitan, y además la información que ofrece está desactualizada en algunos casos. 

Ofrece ayudar en los siguientes aspectos:

- Correlativas para cada materia. (Funcion principal y del cual surgió la idea del proyecto)
- Ofrecer infomación sobre la materia que se encuetra en las resoluciones de cada materia. Como puede ser nombre de profesores, si es promocional o no, etc.
