# 📋 Estado de Revisión de Planes y Correlativas

Este documento sirve para rastrear el estado de verificación de los planes de estudio y sus correlativas en la base de datos `src/db/carrera.json`.

El objetivo es asegurar que la información mostrada en la aplicación sea correcta y esté actualizada.

## 🤝 ¿Cómo contribuir?

Si encuentras un error o quieres verificar una carrera, por favor:
1.  Revisa la información en la app.
2.  Comparala con el plan de estudios oficial de la facultad.
3.  Marca la casilla en la columna **Verificación** si la información es correcta.
4.  Si se cargaron las correlativas pero no se verificaron, marca la columna **Correlativas**.
5.  Si hay errores, reportalos abriendo un Issue.

### Referencia
- ✅ : Correlativas verificadas
- 🚨 : Correlativas no verificadas
- ❌ : Correlativas no cargadas
- 📝 : Plan no cargado
